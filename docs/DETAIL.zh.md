# 校园网看门狗

校园订阅跟着网络走。这个插件只回答两件事：机器现在在哪个网络，以及那还是不是有订阅权限的网络。

## 工具

| 工具 | 作用 |
|---|---|
| `campus_status` | 本地网卡、公网出口地址、已记录的校园网前缀、判定结果 |
| `campus_mark` | 把当前出口地址记录为校园网 |

## 行为

- 出口地址从公共回显服务读取，带两个备用源。
- 记录的前缀取 IPv4 前两段（IPv6 取前两组）。
- `unknown` 表示还没记录过；请在访问正常时先跑一次 `campus_mark`。

## 限制

- 粗粒度前缀无法区分校园 NAT 与同网段的其它网络。
- 插件不登录任何门户，也不切换网络。
